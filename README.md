# علّمني — تطبيق 365 معلومة

هذا مشروع Flutter جاهز لبناء تطبيق Android بصيغة APK.

## محتويات التطبيق
- 365 معلومة موزعة على أربعة مجالات.
- معلومة اليوم مع إمكانية التنقل والعرض العشوائي.
- البحث والتصفية حسب المجال.
- المفضلة محفوظة محليًا على الهاتف.
- الوضع الليلي والنهاري.
- فتح روابط المصادر ونسخ المعلومات.
- واجهة عربية كاملة باتجاه RTL.

## إنشاء APK باستخدام هاتفك فقط (GitHub Actions)
لا تحتاج إلى تثبيت Flutter أو Android Studio على الهاتف. نفّذ الخطوات التالية:

1. أنشئ حسابًا أو سجّل الدخول إلى [GitHub](https://github.com).
2. أنشئ مستودعًا جديدًا (New repository)، وسمّه مثلًا `alemny-app` واجعله Private أو Public.
3. ارفع **محتويات هذا المجلد** إلى المستودع، بحيث يظهر `pubspec.yaml` في الصفحة الرئيسية، ويظهر مجلد `.github/workflows` أيضًا. عند الرفع من الهاتف قد تحتاج إلى تفعيل إظهار الملفات المخفية أو استخدام خيار رفع الملفات عبر المتصفح.
4. افتح تبويب **Actions** في المستودع.
5. اختر سير العمل **Build Alemny Android APK** ثم اضغط **Run workflow** إذا لم يبدأ تلقائيًا بعد الرفع.
6. انتظر حتى تنتهي المهمة بعلامة نجاح خضراء.
7. افتح نتيجة التشغيل الناجح، ثم انزل إلى **Artifacts** واضغط `alemny-release-apk` لتنزيل ملف ZIP.
8. افتح ملف ZIP على هاتفك واستخرج `app-release.apk`، ثم اضغط عليه وثبّته. قد يطلب Android السماح بالتثبيت من هذا المصدر.

## البناء محليًا (اختياري)
يتطلب Flutter SDK وAndroid SDK:

```bash
flutter create --project-name alemny --org com.alemny.app --platforms=android .
flutter pub get
flutter build apk --release
```

سيكون ملف التثبيت هنا:
`build/app/outputs/flutter-apk/app-release.apk`

## ملاحظات
- ملف APK الذي ينتجه GitHub Actions هو نسخة Release موقعة بمفتاح debug الافتراضي الخاص بالبناء، ومناسبة للتثبيت والتجربة الشخصية، وليست إعدادًا للنشر الرسمي على Google Play.
- لا ترفع مفاتيح توقيع خاصة أو كلمات مرور إلى المستودع.
